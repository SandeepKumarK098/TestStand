Standard Test for Adapters

Test Procedure


  • Test specify module dialog, make sure all settings work.
  • Test all configuration options (if any). Make sure next execution has new settings.
  • Make sure parameters and/or data are passed correctly.
  • Test create code for all settings/module types (if applicable). Test Code Templates if applicable.
  • Test edit code work for all settings/module types (if applicable).
  • Test step into if applicable.
  • Test step out if applicable.
  • Test setting breakpoints within the code if applicable.
  • Create test sequence of steps calling modules using the adapter.
  • Test any applicable code templates.
  • Test calling at least one API entry point.
  • Test Read-Only version of specify module dialog by breakpointing on step and then specify module from the Execution display.
  • After running a step you will probably not be able to rebuild the module. Test that doing Unload All Modules allows you to rebuild again.
