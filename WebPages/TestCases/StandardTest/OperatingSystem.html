Standard Test for Operating System


Test Description


Install, run samples, create and run sequences, run operator interfaces, view reports on new OS. Also, run LV and CVI computer and auto sequences. Configure CVI to run in external process. Run with TestUUTs for several uuts. Make sure all dialogs that should come to the front do come to the front

All tests should be run on a release build installed via the installer.

Test Procedure


  • Run the following sanity checks:
    • Load and run /tests/alltests.seq
    • Convert and run an old LV sequence
    • Convert and run an old cvi sequence
    • Run the text and html documentors on the model sequence file
    • Run computer.seq in editor and all gui's
    • Export/import limits from computer.seq to excel file
    • Create LV test, step into
    • Create CVI test, step into
    • Load computer.seq from the previous version released to customers. Verify that it handles NI type changes silently
    • Verify that the build is a release build by making sure the sequence call specify module dialog does not have an asynchronous checkbox
    • Load auto, computer. dllperf, lvperf, cviperf, and beepforever. run four instances of beepforever. While the are running, open and close other files, run other files, create and run new files. Finally, exit the sequence editor while they are running.
    • Test the simple operator interfaces for CVI and LV
