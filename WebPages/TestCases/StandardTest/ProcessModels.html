Standard Test for Process Models

Test Procedure


  • Test all entry points
  • Test all callbacks (write sequences)
  • Test all report options
  • Test all database options
  • Test all model options (if applicable)
  • Run Test UUT's in all GUIs, make sure serial number and pass/fail dialogs work ok
      • For batch model.
        1. In a new sequence override the PreBatch call back.
        2. Add a statement in the end of the call back.
        3. Set the batch serial number and UUT serial number for all UUTs using the following syntax.
        4. Parameters.ModelData.BatchSerialNumber = 90
        5. UUT serial number can be set for the first UUT using the following syntax.
        6. Parameters.ModelData.TestSockets[0].UUT.SerialNumber = 13
        7. Run the sequence and ensure that the batch results dialog shows the appropriate Batch serial number and UUT serial number.

      • For parallel model.
        1. In a new sequence override the PreUUT call back.
        2. Add a statement in the end of the call back.
        3. Set the UUT serial number using the following syntax.
        4. Parameters.UUT.SerialNumber = "TestUUTSerialNumber"
        5. Run the sequence and ensure that the parallel results dialog shows the appropriate UUT serial number.
  • Test all report formats in all GUI's (sequence editor, VB gui, CVI gui)
  • Verify that interactive results are annotated as such in the report
