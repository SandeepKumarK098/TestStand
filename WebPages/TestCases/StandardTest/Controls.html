Standard Test for Controls

Standard Test


Test Description


Verify the FUNCTIONALITY of every action/option in all environments.

Test Procedure


  • Test printing in all environments
  • Test all configurations of new border functionality
  • All methods and properties of the control
  • All events are fired
  • Draws correctly when you change visual properties/methods
  • All methods and properties return error codes when invalid data is passed
  • You should be able to drop the control in all containers - CVI, LV, VB, VC++, .Net
  • Invoke methods and properties and pass invalid values and make sure that you get error messages from the controls
  • Check to see if all strings are translated in all dialogs, property pages, and error messages.
  • Invoke all controls on the property page and check to see if they do the required action
  • Open all property pages of controls and changes values check that the changes are saved when you make changes.( Save your project and reopen the project and make sure that the changes were saved.)
  • In property pages - test that clicking the help button opens up the help file at an appropriate topic.
  • Make sure that tooltips show the correct text for the control (if supported)
