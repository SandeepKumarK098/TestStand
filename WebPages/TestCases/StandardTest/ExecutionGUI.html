Standard Test for Execution GUIs

Test Procedure


  • Test with intellimouse
  • Test all menu items, controls, and buttons to make sure they are functional
    • Are they dimmed at the right times
    • Test in all execution states: (running, breakpointed, complete)
    • Turn tracing on and off, set breakpoints, etc..
  • Test unloading and loading sequences, set breakpoints before starting and execution and after starting one.
  • Test loading a sequence file with a type conflict (It should prompt to resolve conflicts)
  • Test stepinto, stepover, stepoutof, break, continue, terminate, abort, set next step
  • Test call stack
  • Test report
  • Test runmode of steps (both in sequence window and execution window)
  • Test thread ring (when we have version 2.0)
  • Test that the execution window's menu is appropriately altered when execution starts and stops
  • Test terminate and abort prompt when trying to close a running execution window
  • Test interactive execution (run and loop on selected tests)
    • Test on steps when when breakpointed in sequence
    • Test on sequene that is not yet executing
    • Test terminate and abort while executing interactive (both when running and when at a breakpoint)
    • Verify that you can't start an interactive execution when you are already in one
    • Test from breakpoint caused by a runtime error
    • Test from breakpoint while looping on a step
    • Test that a runtime error during interactive execution results in going to cleanup after interactive execution finishes
  • Test multiple simultaneous executions
  • Test with users of various privileges
  • Test with no user logged in
  • If there is an about box, verify that the version number and other information is correct
  • Test opening a file by drag and drop from windows explorer. For majik applications, you can drop onto a SequenceView or ListBar control.
  • Test shutting down corner cases
    • Verify that you can close the GUI while executing a sequence
    • Verify that you can shut down windows or log off windows while the GUI is open
    • For UIs, try the above tests in Operator and Editor mode
