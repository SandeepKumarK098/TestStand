Testing TestStand VIs in LabVIEW palette

LabVIEW Build Validation



Test Description

Make sure that the TestStand VI Palette in LV works as expected. Most of the VIs are used in LV Operator Interfaces and compatibility must be ensured.

Test Procedure

 

  1. Install LabVIEW (8.0 or later) on a clean machine.
  2. Install TestStand (3.5 or later).
  3. Create various VIs that use the VIs in the TestStand Palette under LabVIEW.
    • Run the VIs in LabVIEW and ensure you get the expected behavior or data.
  4. If you are testing with TestStand 3.5,4.0.x or 4.1, run the test sequence below //TestStand/Tests/TS Automated Tests/3.5/LabVIEWPaletteVIs/
  5. If you are testing with TestStand 4.5 and later, also run the test sequence below //TestStand/Tests/TS Automated Tests/4.5/LVTests/8.0/PalletteVIs/.
    • Using the development environment with the current version of LabVIEW.
    • Create a deployment for the PallettesVIs directory. Once it's done run the PaletteVIs.seq from the image directory with the LabVIEW adapter set to use the RTE with the LabVIEW version used to create the deployment, don't use autodetect.
  6. If you are testing with TestStand 4.0 or later:
Open the full-featured LabVIEW UI with the current version of LabVIEW
·        
      1. Resize the UI
      2. Resize the variables view and the sequence list· 
      3. Finally rebuild the UI using the current version of LabVIEW and make sure it works as expected
NOTE: The previous steps verify that the VIs used as part of the UI construction are tested.
  1. Verify that help integration works correctly for the VIs in the TestStand Palette, to do this run //TestStand/WebPages/TestCases/Documentation/Media/TSLVHelpIntegration-Top Level.vi.
