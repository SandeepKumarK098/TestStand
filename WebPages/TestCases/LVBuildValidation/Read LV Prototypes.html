Test Case Scenario
National Instruments Confidential

Read LabVIEW Prototypes

LabVIEW Build Validation



Test Description

Read LabVIEW prototypes using the runtime and development environment.

Test Procedure

 

  1. Install  LabVIEW on a clean machine.
  2. Install TestStand .
  3. Sync //TestStand/Tests/LV Automated Tests_New/TestVIs, masscompile them in LabVIEW and Sequence //TestStand/Tests/LV Automated Tests_New/TestSequences/ from perforce
  4. Open TestStand and set the environment to runtime on the LV adapter: Configure >> Adapters >> LabVIEW, click "Configure" and select LabVIEW Run-Time Engine.
  5. Use VIs already created or create new ones in LV, don't create the VIs from TestStand.  Be sure to try all of the VIs in //TestStand/WebPages/TestCases/LVBuildValidation/Media/Prototype VIs/
  6. Pick 5 VIs from //TestStand/Tests/LV Automated Tests_New/TestVIs/
  7. Add a LabVIEW action step to a sequence, open the specify module dialog for it and make sure that all the prototypes from the VIs can be read.
  8. Set the environment to deveploment(active version) on the LV adapter: Configure >> Adapters >> LabVIEW, click "Configure" and select development system
  9. Add a LabVIEW action step to a sequence, open the specify module dialog for it and make sure that all the prototypes from the previous VIs can be read.
  10. Pick 5 VIs from the automated parameter testing and add code to verify that the data passed into the VI from TestStand is correct.  See VIs Control21000.vi and Control21701.vi as examples.
    • Sequence //TestStand/Tests/LV Automated Tests_New/TestSequences/TestSequence.seq
    • VIs //TestStand/Tests/LV Automated Tests_New/TestVIs/
