Test Case Scenario
National Instruments Confidential

Create and Execute Normal VIs

LabVIEW Build Validation



Test Description

Make sure that creating and executing normal VIs works as expected. The idea is to exercise the code that interacts with VIs from TestStand, so create various VIs using action, pass/fail test steps and so on.

Test Procedure

 

  • Install latest LabVIEW Build (8.0 or later)
  • Install the latest Driver CD select the following items:
    • NI-DAQmx (8.0 or later)
    • Traditional NI-DAQ (7.4 or later)
    • NI-488 (2.2.4 or later)
    • NI-VISA (3.4 or later)
    • IVI Compliance Package (2.3 or later)
  • Install the latest version of TestStand. 
  • Add some LV steps to a sequence using action, pass/fail test step types and so on. Create VIs for them from TestStand. Some with one parameter, others with more and select different data types.
  • Run the sequence and validate that it works as it should.
  • Try Enabling and disabling tracing.
  • Debug the sequence, step into the steps, step out from LV and, set breakpoints in the VIs, and so on. Test all available debugging options.
  • Call the following types of VIs, with and without a LV project configured:
    • A VI that is part of a LLB you add a VI to an LLB when saving there is a button to create an LLB.
    • A VI that uses a subVI that is part of a project library- create a LV project then create a library in project and add VI to project library.   Drag & drop the VI from the project into another VI to create a subVI.
    • A VI that is part of a project library.
    • A VI that uses a global DAQmx Task. You do not need special hardware for this, but you do need to create a DAQmx Task in MAX.   Start MAX- you can create a simulated DAQ device, then create a task on that device.
    • A VI that uses an XControl. You create an XControl by right clicking on 'My Computer' in a LV project and selecting New>>XControl. Use the VI in //TestStand/WebPages/TestCases/LVBuildValidation/Media/Xcontrol
    • A VI that uses a type definition. See 'type definitions, creating (how-to)' in the LV help for instruction on how to create a type definition.
    • A VI that uses GPIB. You need GPIB hardware for this test.   There is a GPIB example in the LAbVIEW examples.
    • A polymorphic VI  //TestStand/WebPages/TestCases/LVBuildValidation/Media/PolymorphicVI has an example VI.
    • A VI that uses shared Variables. You create a shared Variable by right clicking on 'My Computer' in a LV project and selecting New>>Variable.
    • An Express VI.
    • A VI from the LabVIEW analysis library (i.e. Mathematics->Probability and Statistics\Mean.vi)
    • A VI that uses an XNode.  //TestStand/WebPages/TestCases/LVBuildValidation/Media/XNode
    • Note: If you need help on how to call one don't hesitate to talk with José or Rick.
  • Use the files stored in //TestStand/WebPages/TestCases/LVBuildValidation/Media/CreateExecuteNormalVIs as reference.
