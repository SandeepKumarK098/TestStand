ActiveX/COM Adapter

Adapters


Test Description


Test all possible options. Look at the adapter documentation to help you better understand all the options available.

Test Procedure


  • Make sure custom only interfaces work (need to write these with VC)
  • Make sure the Engine.InternalOption setting InternalOption_ForceAutomationAdapterToUseDispatchForDualInterfaces works. You must verify that dispatch is being used instead of custom interface. This is easiest to do with VC written server. Set breakpoints, see how call is made (i.e. through invoke or through direct call to custom interface).
  • Try numerous different data types
  • Standard Test for Adapters
  • Standard Test for Dialogs
