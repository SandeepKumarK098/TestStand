Test Case Scenario
National Instruments Confidential

Code Templates

Adapters



Test Description

 

Test all possible options. Look at the adapter documentation to help you better understand all the options available.

Test Procedure

 

·         Code Template

o        Create, Add, Remove code templates in the Step Type Properties dialog

o        Edit code templates in edit code template dialog

o        Copy an existing code template into the User folder and make sure you can add it to a step type using the Add… button.

o        Test the special token %ReturnValue which you can use in the Parameter Name field of the Edit Code Template dialog to specify the return value of the function.

o        Make sure the Result Action and Set Error.Code to Value fields work correctly

o        Legacy templates: C/CVI Pass Sequence Context option

o        Add multiple LabVIEW, CVI, DLL templates to a step type and use the CreateCode button for those adapters to verify that the Choose Code Template dialog appears. For the CVI and DLL module panels, verify that the Choose Code Template dialog does NOT appear. The Code Template combo box already specifies the code template.

o        Use CreateCode in all adapters and verify that parameters are filled in appropriately from the template.

·         Standard Test for Dialogs
