Test Case Scenario
National Instruments Confidential

Older components integration

Backwards Compatibility



Test Description

 

The purpose of this test is to simulate a user that modified components (copied them to the TestStand Public directory and made changes) to make sure such a user is not likely to run into anything that keeps it from working out of the box.
Make sure process models from previous versions and other components still work when used from TestStand. One way to do this is install all previous versions, copy models and other components to the TestStand Public directory.
Make sure user components are used and work correctly. Test around this to see if using them causes unexpected problems.

Test Procedure

 

1. Install few of the previous versions of TestStand. (ex. TS 2012, TS 2016)
2. For testing models older than TS 2012, use LegacyModelSwitcher.exe to switch to legacy models.
3. Execute few sequence files in Singel Pass\Test UUT and verify no unexpected errors are thrown.
4. Launch the tool again and switch back to using New Models.
5. For testing models from TS 2012 and later, copy the model file from previous version of TestStand to TestStand Public directory of current version.
(ex. <TestStand>\Components\Models\TestStandModels\SequentialModel.seq from TS 2012 to <TestStand Public>\Components\Models\TestStandModels in current version and save with a different name)
6. In Sequence Editor, change the Station Options-->Model to use the model file from TestStand Public directory.
7. Execute few sequence files in Singel Pass or Test UUT and verify no unexpected errors are thrown.

For TS 2017 and later only: In TS 2017 there are few changes to model files which requires the user to copy few more files manually if using old components from TS versions 2012 to 2016

1. <TestStand>\Components\Models\TestStandModels\SequentialModel.seq from TS 2012\2016 to <TestStand Public>\Components\Models\TestStandModels in TS 2017 and save with a different name.
2. <TestStand>\Components\Models\TestStandModels\ModelSupport.seq from TS 2012\2016 to <TestStand Public>\Components\Models\ModelPlugins\ModelSupport.seq in TS 2017.
3. If using TS 2012 or 2013, <TestStand>\Components\Models\TestStandModels\modelsupport2.dll from TS 2012\2013 to <TestStand Public>\Components\Models\TestStandModels\modelsupport2.dll in TS 2017.
4. If using TS 2012 or 2013, <TestStand>\Components\Models\TestStandModels\modelpanels.uir from TS 2012\2013 to <TestStand Public>\Components\Models\TestStandModels\modelpanels.uir in TS 2017.
5. If using TS 2014 or later, <TestStand>\Components\Models\TestStandModels\modelsupport2\ from TS 2014\2016 to <TestStand Public>\Components\Models\TestStandModels\modelsupport2\ in TS 2017.
6. <TestStand>\Components\Models\TestStandModels\reportgen_atml.seq from TS 2012\2016 to <TestStand Public>\Components\Models\TestStandModels\reportgen_atml.seq in TS 2017.
(Repeat same for other report plugin sequence files.)
7. <TestStand>\Components\Models\ModelPlugins\NI_DatabaseLogger.seq from TS 2012\2016 to <TestStand Public>\Components\Models\ModelPlugins\NI_DatabaseLogger.seq in TS 2017.
8. <TestStand>\Components\Models\ModelPlugins\NI_OfflineResultsGenerator.seq from TS 2012\2016 to <TestStand Public>\Components\Models\ModelPlugins\NI_OfflineResultsGenerator.seq in TS 2017.
9. <TestStand>\Components\Models\ModelPlugins\NI_ReportGenerator.seq from TS 2012\2016 to <TestStand Public>\Components\Models\ModelPlugins\NI_ReportGenerator.seq in TS 2017.
10. In Sequence Editor, change the Station Options-->Model to use the model file from TestStand Public directory.
11. Open <TestStand Public>\Components\Models\ModelPlugins\ModelSupport.seq in TS 2017 and update the prototype of "Wait if thread limit exceeded" step in "Model Plugins - Pre Batch" and "Model Plugins - Pre UUT" sequences.
a. Specify Parameters.ContinueTesting for "WaitNow" parameter.
12. Execute few Example sequence files in Single Pass and Test UUTs and verify no unexpected errors are thrown.
