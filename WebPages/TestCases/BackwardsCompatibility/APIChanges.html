API Changes

API Changes

Backwards Compatibility


Test Description


Make sure that all API changes are backwards compatible.

Test Procedure


Run the type library diffing tool located here:

//TestStand/Users/Jimmy/TypeLibDiff/Debug/TypeLibDiff.exe

Enable the 'Show Binary Changing Differences Only' option. Diff each of the type libraries for the following APIs for the current version of TestStand with their corresponding type library from the previous version of TestStand:

  1. Core TestStand API (teapi.dll)
  2. Adapters API (TsAdpApi.tlb)
  3. UI Controls API (tsui.dll)
  4. UI Controls Support API (tsuisupp.dll)
  5. Session Manager API (TsSEManager.dll)

The Type Libarary Differ shows additions in blue and deletions in red and struck out. Additions are OK but any deletions should have a good reason and should be investigated.
