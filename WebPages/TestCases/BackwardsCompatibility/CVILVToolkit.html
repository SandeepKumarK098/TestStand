Converting LV and CVI Toolkit sequences

Converting LV and CVI Toolkit sequences

Backwards Compatibility


Test Description


Verify that a new TestStand release can work with converted LV and CVI Toolkit sequences.

Test Procedure


  • Install the CVI and LV Toolkils:
    • \\nirvana\niinstallers\Old\CVI\Toolkits\TestExec\2.0.1
    • \\nirvana\niinstallers\Old\LabVIEW Toolsets\TestExecutive

    On Vista you should install them to a directory that's writeable (not in C:\Program Files)

  • Acquire a suite of CVI and LV toolkit sequences. You can use the example sequences that come with the toolkits.

  • Convert the toolkit sequences. If you're using the examples from the CVI and LV toolkits, it's best to save the converted sequences to the same directory as the original sequences so you don't break the relative paths.

  • Verify that they run and all options were converted correctly.
